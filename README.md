# 🖩 Calcolatrice Semplice in C++

Questa è una **calcolatrice testuale semplice** scritta in C++. Permette di eseguire le quattro operazioni aritmetiche di base tra due numeri interi.  

## ⚡ Funzionalità
- Inserimento di **due numeri** da parte dell’utente.  
- Scelta dell’operazione tramite un menu numerico:  
  - `1️⃣` Somma  
  - `2️⃣` Sottrazione  
  - `3️⃣` Divisione  
  - `4️⃣` Moltiplicazione  
- Controllo della **divisione per zero** con messaggio di errore.  
- Stampa del **risultato** dell’operazione scelta.  

## 🛠️ Come funziona
1. Il programma richiede di inserire due numeri interi.  
2. Chiede quale operazione eseguire.  
3. Esegue l’operazione selezionata e mostra il **risultato**.  
4. Gestisce input non validi per l’operatore e divisioni per zero.
